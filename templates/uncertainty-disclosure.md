# 不确定性披露模板

用于在研究报告中规范披露不确定性和风险。

---

## 一、不确定性类型

### 1. 来源冲突

不同来源对同一事实的说法不一致。

```markdown
⚠️ 来源冲突

**冲突点**：[具体事实]

**来源 A**：
- 说法：[内容]
- 来源：[来源名称]
- 类型：[官方/权威/媒体/二手/社交]
- 时间：[发布时间]
- 链接：[URL]

**来源 B**：
- 说法：[内容]
- 来源：[来源名称]
- 类型：[官方/权威/媒体/二手/社交]
- 时间：[发布时间]
- 链接：[URL]

**可信度分析**：
- [分析两个来源的可信度差异]
- [考虑发布时间、来源类型、内容完整性等因素]

**结论**：
- [目前无法确定 / 倾向于来源 A / 需要进一步核验]
```

### 2. 单一来源

仅有单一非官方来源支撑结论。

```markdown
⚠️ 单一来源

**事实**：[具体内容]

**来源**：
- 名称：[来源名称]
- 类型：[来源类型]
- 时间：[发布时间]

**风险**：
- 仅有一个来源，无法交叉验证
- 来源类型为 [非官方/二手/社交]，可信度有限

**建议**：
- 寻找其他独立来源
- 查找官方文档或公告
- 对该结论持审慎态度
```

### 3. 信息缺失

无法获取关键信息。

```markdown
⚠️ 信息缺失

**缺失内容**：[无法获取的信息]

**原因**：
- 页面不可访问
- 需要登录或权限
- 信息未公开
- 搜索未找到相关来源

**影响**：
- [对结论的影响]

**建议**：
- [如何获取缺失信息]
- [替代信息来源]
```

### 4. 时效性问题

信息可能已过时。

```markdown
⚠️ 时效性说明

**信息**：[具体内容]

**来源时间**：[发布时间]

**时效性风险**：
- 信息发布于 [X] 年前
- 该类型信息通常变化频率为 [高/中/低]
- 可能有更新版本或变更

**建议**：
- 查找最新官方来源
- 确认信息是否仍然有效
- 关注相关公告或更新
```

### 5. 推断性结论

结论依赖推断而非直接证据。

```markdown
⚠️ 推断性结论

**结论**：[推断得出的结论]

**依据**：
- [证据 1]
- [证据 2]
- [证据 3]

**推断逻辑**：
- [说明如何从证据推断出结论]

**不确定性**：
- 缺乏直接证据
- 存在其他可能解释
- 推断可能不准确

**建议**：
- [如何验证推断]
- [需要寻找的直接证据]
```

## 二、不确定性披露位置

### 在报告中的位置

1. **执行摘要**：如有重大不确定性，在摘要末尾简要说明
2. **关键发现**：在相关发现后紧跟不确定性说明
3. **限制与边界**：集中说明所有不确定性和风险
4. **后续研究问题**：建议如何解决不确定性

### 格式建议

- 使用 ⚠️ 图标标记
- 使用引用块格式（> ）突出显示
- 保持简洁，避免过度描述

## 三、完整示例

### 示例 1：来源冲突

```markdown
## 关键发现

### 发现 1：公司营收情况

根据财经媒体报道，该公司 2024 年营收约为 50 亿美元。

> ⚠️ 来源冲突
>
> **冲突点**：2024 年营收数据
>
> **来源 A**：50 亿美元 — 财经媒体 A（主流媒体，2025-01）[链接]
> **来源 B**：45 亿美元 — 行业报告 B（权威机构，2025-02）[链接]
>
> **分析**：两个来源均为可靠来源，但数据存在差异。财经媒体可能基于非官方渠道，行业报告可能基于估算。
>
> **结论**：目前无法确定确切数字，建议查阅公司官方财报。

### 发现 2：...
```

### 示例 2：多重不确定性

```markdown
## 限制与边界

> ⚠️ 不确定性说明
>
> 本研究存在以下不确定性：
>
> **1. 来源冲突**
> - 营收数据存在两个不同说法（见发现 1）
>
> **2. 单一来源**
> - 部分产品规格仅来自媒体报道，未找到官方确认
>
> **3. 时效性问题**
> - 竞争格局分析基于 2024 年中数据，可能已发生变化
>
> **4. 信息缺失**
> - 未能获取公司最新财报（未公开）
> - 部分海外市场数据不可获得
>
> **总体评估**：研究结论可信度中等，建议在关键决策前进一步核验。

## 后续研究问题

1. 获取公司最新官方财报，确认营收数据
2. 查找产品规格的官方文档
3. 更新竞争格局分析，纳入最新市场动态
```

## 四、不确定性程度分级

| 等级 | 描述 | 处理建议 |
|------|------|----------|
| **低** | 有官方来源，仅次要信息不确定 | 可直接使用，简要说明 |
| **中** | 多个来源略有差异，或部分信息缺失 | 需说明不确定性，建议核验 |
| **高** | 来源冲突明显，或关键信息缺失 | 必须明确标注，不建议直接用于决策 |
| **极高** | 核心结论缺乏可靠来源 | 必须明确标注"无法确定"，建议放弃或重新研究 |

---

## 五、披露原则

1. **透明性**：如实披露所有已知不确定性
2. **及时性**：在相关发现后立即披露
3. **清晰性**：使用简洁明了的语言
4. **建设性**：提供解决不确定性的建议
5. **区分度**：区分事实、推断和不确定内容
